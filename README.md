# 浮词

### 摸鱼的时候，学学语言。

**把每一次走神，变成和新单词的偶遇。**

等文件加载的几秒，等消息回复的片刻，工作间隙偷偷放空的一分钟——让浮词待在桌面一角，随手看一个单词，点开意思，听听发音。

摸鱼也可以有一点小收获。今天眼熟一个词，明天多懂一句话。让学习轻一点，让空闲有趣一点。

[下载安装](https://github.com/ltwyz55-a11y/wordfloat/releases/latest) · [浏览源码](https://github.com/ltwyz55-a11y/wordfloat)

## 设计概念

浮词想把语言学习放进日常的小空隙里。

一张小卡片，像桌面上的便签，安静地留在视线一角。单词先出现，好奇时再点开释义；想听就听，想换就划。学习可以从一次随手点击开始，也可以在工作继续时轻轻收起。

界面围绕「一个词，一点注意力」展开：小巧的圆角、轻盈的半透明背景、清晰的文字，把重点留给眼前的单词。卡片的位置、大小、颜色和壁纸由你决定，让它自然融入自己的桌面。

当前功能围绕英文单词的理解与听读展开。用一点零碎时间，让陌生的拼写慢慢变得熟悉。

**给忙碌留一点空白，给摸鱼加一点新知。**

## 随手学，轻轻放

- **看一眼**：小卡片悬浮在桌面一角，随时可见。
- **点一下**：展开释义，再次点击收起；点击喇叭听发音。
- **划一下**：左右切换单词，保持轻快的学习节奏。
- **挪一挪**：拖动位置、缩放大小，为当前工作留出空间。
- **换个样子**：调整背景与字体颜色，搭配自己的图片壁纸。
- **顺手查**：在主页面输入英文或中文，查询释义和发音。

设置与学习位置保存在本机，下次打开接着来。声音使用系统已安装的语音。

## 下载与开始

| 平台 | 版本要求 | 打开方式 |
|---|---|---|
| macOS | macOS 13 及以上；当前下载包为 Intel 版 | 解压后将「浮词.app」放入「应用程序」 |
| Windows | Windows 10 22H2 / Windows 11，x64 | 下载 Setup 安装程序，按向导完成安装 |

**[前往最新下载页](https://github.com/ltwyz55-a11y/wordfloat/releases/latest)**

打开主页面，点击「悬浮学习」即可开始。双击卡片返回主页面；关闭主窗口或选择菜单中的「退出」，会一起关闭悬浮卡片。

Mac 版为临时签名构建；Windows 版尚未进行发布者代码签名。实际验证范围与详细操作分别见 [Mac 验收记录](VALIDATION.md)、[Windows 使用说明](Windows/README.md) 和 [Windows 验收记录](Windows/VALIDATION.md)。

## 从源码构建

Mac 安装 Swift 5.9 及以上的 Xcode 或命令行工具，在项目根目录运行：

```sh
sh Scripts/swift.sh test
sh Scripts/package.sh
```

打包结果位于 `outputs/`。Windows 构建步骤见 [Windows 开发说明](Windows/README.md#从源码构建)。
