# 浮词

源码与发行包：[GitHub 仓库](https://github.com/ltwyz55-a11y/wordfloat)、[最新下载](https://github.com/ltwyz55-a11y/wordfloat/releases/latest)。当前仓库为私有，需要登录获授权的 GitHub 账号。

一款在 Mac 桌面上方陪你记单词的小卡片。支持 macOS 13 及以上。本次构建为 Intel（x86_64）版本，与当前电脑匹配；其他架构可从源码重新构建。

## Windows 版本

Windows 10/11 x64 版位于 `Windows/`，与 Mac 版共用离线词库与学习详情，提供安装程序、桌面／开始菜单入口、悬浮卡片及系统托盘控制。详见 [Windows 使用说明](Windows/README.md) 和 [Windows 验收范围](Windows/VALIDATION.md)。当前 Windows 安装与桌面效果尚未在实机验证，编译和 EXE 资源校验不代表实机通过。

## Mac 打开与使用

当前电脑已安装到访达「应用程序 → 浮词」，双击即可打开。仅保留这一份最新应用；首次打开会显示词本主页面。自行构建时，打包脚本也会生成可分发的 ZIP。

- 选择词本，点击「悬浮学习」。
- 单击单词：仅显示释义，不自动发音；展开后再次单击英文或中文释义，恢复为自己调整过的小卡片尺寸（默认 260×150）。需要发音时点击小喇叭。
- 左滑进入下一词，右滑回到上一词。支持在内容区域用鼠标横向拖动或触控板横向滑动；首尾循环。
- 鼠标移入卡片后显示小箭头，也可以点击翻词。
- 拖动卡片顶部的窄区域可以移动位置。
- 鼠标移到边缘或四角，出现缩放光标后拖动即可调整大小。宽度限制为 220～520，高度为 130～420；展开释义时最小高度为 200（Mac 为逻辑点，Windows 为缩放前的逻辑单位）。
- 收起、展开分别记住高度，共用宽度；翻词和再次单击收起时恢复自定义小卡尺寸。退出后再打开也会保留尺寸。缩放不触发翻词或发音，正文仍可滚动。
- 双击卡片内容打开主页面。为区分单击与双击，单击会等待系统双击判定时间。
- 主页面顶部「查单词或中文释义」可直接查询全部内置词库；点击「听发音」朗读结果。⌘F 聚焦查词栏，清空后返回词本。词本筛选和「浏览词条」仍可单独使用。
- 点击主页面左上角的红色关闭按钮会完全退出应用，桌面卡片和菜单栏图标一起关闭。需要回到卡片时，点击「悬浮学习」。菜单栏的叠卡图标也可以隐藏／显示卡片、打开词本或退出应用。
- 主页面左下方可切换英音、美音。主页面快捷键：⌘1 打开词本，⌘2 悬浮学习，⌘Q 退出。

词本和学习进度保存在本机，无需账号。应用不会联网查询单词、上传学习记录或使用付费接口。系统已安装的英语语音可离线发音；缺少语音时，可在 macOS 系统设置的辅助功能／语音相关选项中下载英语声音。

已安装时，可随时在访达「应用程序」中双击「浮词」重新打开；退出后再次打开会保留学习进度和卡片外观。

## 主页面查词（Mac 1.4.0 / Windows 1.3.0）

在主页面顶部输入英文单词、短语或中文关键词，输入后直接显示查询结果。支持大小写与首尾空格，精确匹配优先，其次为单词前缀；同词跨词本出现只显示一次。每次最多显示 100 条，输入更完整的内容可缩小范围。

选中结果可查看音标、词性、完整中文释义、所属词本和领域释义，以及已收录的词源、词形和双语例句。点击「听发音」才播放，输入、选词和展开不会自动朗读。例句保留中英文朗读和来源入口。

查词不切换正在学习的词本，也不改写浏览位置。清空查询或点击词本分类即可返回原页面；Mac 按 ⌘F、Windows 按 Ctrl+F 可聚焦搜索栏。Windows 也可按 Esc 清空查询。

查询覆盖应用内置的 12,369 个独立词条，包含十个词本的通用与领域释义，可断网使用；不是联网词典。未收录时会明确提示，缺少的音标、词源或例句不会自动补造。发音仍依赖本机已安装的系统声音。

## 词典详情与记忆辅助（1.2.0）

单击卡片展开中文后，在正文区域向下滚动，可依次查看词典完整释义、词根与词源、词形变化、中英例句、补充义项和英英释义。卡片保持小巧，长内容可以一直滚动到底；重新翻词后回到顶部。

- 词典完整释义保留内置来源中的所有翻译；专业领域释义优先展示，通用词典含义另列。
- 例句下方有「英文」「中文」「中英连读」按钮。中英连读先读英文，再读中文；点击其他朗读或翻词会停止旧发音。
- 点击例句朗读按钮不会收起卡片；再次单击正文仍可恢复最小卡片。双击正文打开主页面。
- 词源及例句采用有出处的离线资料，不猜造缺失词根。当前 1,563 个词有词源、5,158 个词有例句（共 12,086 对）；没有收录的内容会显示「暂无」提示。
- 例句按通用用法匹配，不一定对应当前专业词义。来源可能有翻译偏差；点击「查看来源」可在浏览器核对（该操作需要联网）。例句署名与许可保留在正文中。
- 中文朗读需要已安装中文系统声音；缺少声音时会提示下载。断网仍可查看全部内置内容并使用已安装的中英语音。

## 卡片外观（1.1.0）

双击卡片打开主页面，在左侧选择「卡片外观」。所有更改即时预览、自动保存；点击「悬浮学习」即可使用。

- 六种预设：跟随系统、雾面玻璃、清透玻璃、暖白纸卡、鼠尾草、午夜蓝。
- 点击「卡片颜色」或「字体颜色」旁的色块，使用系统色盘自由选色。字体颜色也用于音标、释义和小喇叭。
- 可切换磨砂、清透、纯色；染色浓度滑块调整玻璃上的颜色覆盖程度。磨砂使用 macOS 的实时背景模糊，实际效果随背后的桌面变化。系统开启「减少透明度」时使用实色背景。
- 点击右上角「图片壁纸…」，选择不超过 50 MB 的 PNG、JPEG、HEIC 或 TIFF。图片居中裁切；可调整蒙层颜色和浓度，提高文字可读性。
- 图片会保存到应用自己的本地目录，移动原图不影响使用。切换预设仍保留已导入图片，可通过「背景效果 → 图片」切回；「移除图片」仅删除应用保存的副本。
- 「恢复默认」回到跟随系统的外观。「显示释义」开关只切换预览，不改变当前学习状态。

壁纸仅在本机使用，不上传。自定义外观不影响单击收起、双击打开主页面及滑动翻词。

## 从源码构建

安装兼容的 Xcode 或 Swift 命令行工具（Swift 5.9 及以上），在项目目录执行：

```sh
sh Scripts/swift.sh test
python3 Scripts/test_import.py
python3 Scripts/test_learning_import.py
sh Scripts/package.sh
```

打包结果在 `outputs/`。脚本优先使用 `/Applications/Xcode.app` 中的工具链，并将缓存放在项目内；可通过 `DEVELOPER_DIR` 指定其他工具链。不修改系统全局配置。

无需下载原始词库即可构建：筛选后的考试源数据、专业词表、学习详情及 SQLite 数据库已随源码提供。`Scripts/build_data.py` 会验证词条数量、重复项、空释义和数据库约束后生成词库。

原生交互及界面预览检查：

```sh
outputs/浮词.app/Contents/MacOS/WordFloat --diagnostics "$PWD/work/previews"
```

该检查需要可用的 macOS 桌面会话，使用独立临时进度和静音发音替身，结束后退出。实测范围与尚未覆盖的硬件场景见 `VALIDATION.md`。

## 用户导入：剑雅4–19听力答案词（2026-11-22）

新增独立考试词本，来源为用户提供的《剑雅4-19听力答案词.pdf》（文件署名：花生酱罐罐），共 33 页、949 个不重复词条。保留原表顺序和原释义，949 条已逐一核对；原表第 510 条 situational 未给出释义，显示“原文件未提供释义”。原有词典释义与记忆资料不被覆盖；新词缺少的例句和词源不补造。

提取数据与文件 SHA-256 见 `Data/cambridge-listening.json`，导入脚本见 `Scripts/import_cambridge_listening.py`。该材料为用户本地导入，权利归原作者，未将其标为 ECDICT 或 MIT 授权数据。应用中的发音使用本机系统语音。
