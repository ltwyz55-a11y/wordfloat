# Windows 版验收记录

日期：2026-11-22。版本：1.3.1，目标 win-x64。

## 已验证

- 构建环境：当前 Intel Mac、.NET SDK 10.0.402；原生 WPF/Windows Forms 项目编译为 Windows GUI 程序，零警告、零错误。
- 19 组可在构建主机运行的检查：全部词本与领域释义；中英文与字面量搜索；12,304 个详情与来源逐项一致；损坏缓存修复；循环翻词和静音展开状态；独立词本进度及重启恢复；过期／损坏设置回退；六种预设及自定义颜色；壁纸副本保存、恢复和安全移除；无效外观回退；单击／双击／横拖／竖拖互斥；一次横向滚动只翻一词；负坐标屏幕与离屏恢复；中英朗读队列及口音；缺失语言不会使用不匹配的声音。
- 使用与 Mac 版相同的 SQLite，9 个词本、27,642 条词本记录、12,304 个独立词条，源数据校验一致。
- 1.0.0 的历史构建检查：生成真正的 PE32+ x86-64 Windows GUI EXE，采用自包含、非裁剪的单文件部署，内含 .NET 及 Windows Desktop 10.0.13、WPF、Windows Forms 和 System.Speech。
- 1.0.0 的历史构建检查：检查 .NET bundle 清单并解压验证全部内嵌文件；原生机器码与 SDK 的 Windows singlefilehost 模板一致，内置 SQLite 的字节与已验证的数据库一致。校验工具为 `Scripts/verify_windows.py`，格式依据微软 dotnet/runtime 的 Manifest/FileEntry 实现。
- 应用内和交付包包含词库来源、ECDICT MIT 许可、.NET 及 Windows Desktop 许可和第三方声明。
- 当前所有源码修改均按小步编译／检查后独立提交；不执行远程推送。

## 1.2.0 独立安装向导

- 新增原生 Windows Forms 安装器，包含欢迎、安装设置、安装进度和安装完成四页；支持桌面快捷方式选择、完成后立即启动、打开安装文件夹，以及失败后查看日志和重试。界面已交叉编译，尚未在 Windows 实际点击验证。

- 在当前主机运行安装器共用的资源与协议代码：验证完整内嵌包解压和全部应用文件的 SHA-256；拒绝哈希不匹配、声明大小不符、路径穿越及版本不匹配。文件数以随包校验报告为准，不包含调试符号。

- 滚动条内缩以保留卡片边缘缩放区域，沿用系统滚轮、滑块拖动和轨道翻页机制。外观切换时重新应用配色并保留滚动位置，外观预览同步更新。

## 1.1.0 卡片缩放

- 卡片边缘和四角支持鼠标拖动缩放；宽度 220～520，收起高度 130～420，展开高度 200～420，均为逻辑单位。
- 收起和展开分别保存高度，共用宽度；实际设置写入／重启读取、旧版空设置、越界设置回退、角落命中、上下限与对侧边界锚点均有自动检查。
- 缩放优先于正文点击／翻词识别，取消待判定单击；拖动结束恢复屏幕边界并保存尺寸。按当前 DPI 处理屏幕坐标，DPI 或显示器变化时结束当前手势。
- WPF 字体及正文随可用宽度重新排版，保留详情滚动；外观变化不会重置尺寸。
- 已完成零警告交叉编译、18 组核心检查及完整发布文件校验。Windows 诊断入口新增尺寸边界、两种高度、布局截图的窗口状态检查，**尚未在 Windows 执行，物理鼠标缩放、混合 DPI、多显示器仍未实测**。
