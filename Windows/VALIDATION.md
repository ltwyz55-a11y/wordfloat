# Windows 版验收记录

日期：2026-10-20。版本：1.1.0，目标 win-x64。

## 已验证

- 构建环境：当前 Intel Mac、.NET SDK 10.0.402；原生 WPF/Windows Forms 项目编译为 Windows GUI 程序，零警告、零错误。
- 18 组可在构建主机运行的检查：全部词本与领域释义；中英文与字面量搜索；12,304 个详情与来源逐项一致；损坏缓存修复；循环翻词和静音展开状态；独立词本进度及重启恢复；过期／损坏设置回退；六种预设及自定义颜色；壁纸副本保存、恢复和安全移除；无效外观回退；单击／双击／横拖／竖拖互斥；一次横向滚动只翻一词；负坐标屏幕与离屏恢复；中英朗读队列及口音；缺失语言不会使用不匹配的声音。
- 使用与 Mac 版相同的 SQLite，9 个词本、27,642 条词本记录、12,304 个独立词条，源数据校验一致。
- 1.0.0 的历史构建检查：生成真正的 PE32+ x86-64 Windows GUI EXE，采用自包含、非裁剪的单文件部署，内含 .NET 及 Windows Desktop 10.0.13、WPF、Windows Forms 和 System.Speech。
- 1.0.0 的历史构建检查：检查 .NET bundle 清单并解压验证全部内嵌文件；原生机器码与 SDK 的 Windows singlefilehost 模板一致，内置 SQLite 的字节与已验证的数据库一致。校验工具为 `Scripts/verify_windows.py`，格式依据微软 dotnet/runtime 的 Manifest/FileEntry 实现。
- 应用内和交付包包含词库来源、ECDICT MIT 许可、.NET 及 Windows Desktop 许可和第三方声明。
- 当前所有源码修改均按小步编译／检查后独立提交；不执行远程推送。

## 1.1.0 卡片缩放

- 卡片边缘和四角支持鼠标拖动缩放；宽度 220～520，收起高度 130～420，展开高度 200～420，均为逻辑单位。
- 收起和展开分别保存高度，共用宽度；实际设置写入／重启读取、旧版空设置、越界设置回退、角落命中、上下限与对侧边界锚点均有自动检查。
- 缩放优先于正文点击／翻词识别，取消待判定单击；拖动结束恢复屏幕边界并保存尺寸。按当前 DPI 处理屏幕坐标，DPI 或显示器变化时结束当前手势。
- WPF 字体及正文随可用宽度重新排版，保留详情滚动；外观变化不会重置尺寸。
- 已完成零警告交叉编译、18 组核心检查及完整发布文件校验。Windows 诊断入口新增尺寸边界、两种高度、布局截图的窗口状态检查，**尚未在 Windows 执行，物理鼠标缩放、混合 DPI、多显示器仍未实测**。

## 本次启动兼容修复

- 用户报告“Windows 无提示打不开”，未提供系统版本、错误代码或故障电脑日志，因此尚不能确认根因，也未将问题标为实机解决。
- 移除显示窗口前的 SAPI 语音初始化：启动、切词、口音设置、退出均不创建语音服务；首次朗读才初始化。新增回归检查覆盖不可用语音工厂，18 组核心检查通过。
- 最外层入口与 WPF 类型加载分开，记录启动阶段、系统与进程架构、后台异常；失败使用原生 Windows 弹窗指出日志位置。
- 新增 `--safe-mode`，用 WPF 软件渲染和无系统玻璃的卡片启动，以绕过显卡渲染问题；物理显卡兼容性待实测。
- 1.0.1 主交付改为自包含完整文件夹：检查 x64 PE、外部 .NET 零依赖、250 项依赖资产及与 Mac 一致的 SQLite；不再依赖压缩单文件的启动前解压。
- 安装器改为 Windows 内置 PowerShell 脚本，先校验每个发布文件；提供免安装和兼容启动入口，保存 .NET 主机日志、退出代码与对应进程的 READY 状态。已停止旧实例后再替换程序；卸载按清单清理，保留未知文件及学习数据。
- 使用官方 SHA-256 校验的 PowerShell 7.4.21 在 Mac 上实际解析脚本，并执行隔离文件／逻辑模拟：完整清单、缺失及损坏运行库、路径穿越、正常窗口就绪模拟、原生提前退出模拟、环境变量恢复、安全模式参数、保留未知文件的卸载清理。**不是 Windows PowerShell 5.1 或安装／窗口实机验收**。
- 完整 ZIP 逐文件解压、逐文件 SHA-256 校验；启动脚本 UTF-8 BOM、CMD 的 CRLF 行尾，以及依赖缺失／外部运行库／损坏 SQLite 的拒绝检查通过。

## Windows 本机诊断入口

`Diagnose.cmd`（内部调用 `app/WordFloat.exe --safe-mode --diagnostics <输出文件夹>`） 已编译接入，使用独立设置与静音发音替身，不读取或改写真实学习进度。

运行后才会生成对应主机的 `windows-checks.json`：检查置顶配置与尺寸、静音展开和收起、手动发音、主页面切换与词本过滤、完整详情滚动、三种例句按钮、翻词停止旧队列、滚动位置重置、六种预设、壁纸渲染、外观页面和关闭主页面时卡片及托盘退出。可渲染应用自己的窗口截图，不截取其他应用或用户桌面。

当前 Mac 不能执行 Windows WPF 程序，因此交付中只有发布文件格式／资源检查报告，没有伪造的 Windows 本机成功报告。即使该诊断日后通过，也仍不能代替物理发音、触控板和真实 DWM 背景观感检查。
