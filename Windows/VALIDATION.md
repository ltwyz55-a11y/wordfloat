# Windows 版验收记录

日期：2026-10-19。版本：1.0.0，目标 win-x64。

## 已验证

- 构建环境：当前 Intel Mac、.NET SDK 10.0.402；原生 WPF/Windows Forms 项目编译为 Windows GUI 程序，零警告、零错误。
- 15 组可在构建主机运行的检查：全部词本与领域释义；中英文与字面量搜索；12,304 个详情与来源逐项一致；损坏缓存修复；循环翻词和静音展开状态；独立词本进度及重启恢复；过期／损坏设置回退；六种预设及自定义颜色；壁纸副本保存、恢复和安全移除；无效外观回退；单击／双击／横拖／竖拖互斥；一次横向滚动只翻一词；负坐标屏幕与离屏恢复；中英朗读队列及口音；缺失语言不会使用不匹配的声音。
- 使用与 Mac 版相同的 SQLite，9 个词本、27,642 条词本记录、12,304 个独立词条，源数据校验一致。
- 生成真正的 PE32+ x86-64 Windows GUI EXE，采用自包含、非裁剪的单文件部署，内含 .NET 及 Windows Desktop 10.0.13、WPF、Windows Forms 和 System.Speech。
- 检查 .NET bundle 清单并解压验证全部内嵌文件；原生机器码与 SDK 的 Windows singlefilehost 模板一致，内置 SQLite 的字节与已验证的数据库一致。校验工具为 `Scripts/verify_windows.py`，格式依据微软 dotnet/runtime 的 Manifest/FileEntry 实现。
- 应用内和交付包包含词库来源、ECDICT MIT 许可、.NET 及 Windows Desktop 许可和第三方声明。
- 当前所有源码修改均按小步编译／检查后独立提交；不执行远程推送。

## 已实现、尚未在 Windows 实机验证

以下只通过代码编译和相关核心逻辑检查，不能标为实机通过：

- 当前用户安装、更新退出、桌面与开始菜单快捷方式、应用列表注册及卸载。

- Windows 10 与 Windows 11 的兼容性实机运行；ARM64 模拟、32 位 Windows 不在当前验证范围。

## Windows 本机诊断入口

`浮词.exe --diagnostics <输出文件夹>` 已编译接入，使用独立设置与静音发音替身，不读取或改写真实学习进度。

运行后才会生成对应主机的 `windows-checks.json`：检查置顶配置与尺寸、静音展开和收起、手动发音、主页面切换与词本过滤、完整详情滚动、三种例句按钮、翻词停止旧队列、滚动位置重置、六种预设、壁纸渲染、外观页面和关闭主页面时卡片及托盘退出。可渲染应用自己的窗口截图，不截取其他应用或用户桌面。

当前 Mac 不能执行 Windows WPF 程序，因此交付中只有 EXE 格式／资源检查报告，没有伪造的 Windows 本机成功报告。即使该诊断日后通过，也仍不能代替物理发音、触控板和真实 DWM 背景观感检查。
