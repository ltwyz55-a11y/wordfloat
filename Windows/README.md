# 浮词 Windows 版

版本 1.4.1。面向 Windows 10 22H2 / Windows 11，Intel 或 AMD 的 64 位电脑；本包为 x64，不含原生 ARM64 或 32 位版本。

## 1.4.1 外观与滚动修复

- 悬浮窗统一使用无系统边框的透明窗口；同一圆角几何裁切覆盖背景与子内容，移除多余描边。
- 修复半透明背景被强制提高到接近不透明的问题；“背景不透明度”只控制背景，不降低文字清晰度。兼容模式与高对比度保留实色显示。
- 内容位置、滚动条值和滑块值显式同步，支持滚轮、拖动与轨道翻页。
- 主页面去掉宣传语、副标题、重复提示和常驻快捷键说明；保留搜索、分类、词本名称、词数、关键操作和实际错误提示。

## 下载、安装与关闭

1. 下载「浮词-Windows-安装-1.4.1.exe」，在 **Windows 电脑**上双击打开安装向导，无需手动解压。
2. **欢迎页面 → 下一步**：确认安装信息。
3. **安装设置 → 开始安装**：查看安装位置，选择是否创建桌面快捷方式。检测到已安装版本时显示「开始更新」，保留学习进度和外观。
4. **安装进度**：依次校验、解压和安装文件，显示进度与当前步骤。安装前可取消；写入期间请等待完成。
5. **安装完成 → 完成**：成功后明确显示「安装完成」、版本和安装位置。默认勾选「完成后立即启动浮词」；取消勾选则只完成安装，也可点击「打开安装文件夹」。
6. 此后从桌面（如果选择创建）或开始菜单打开「浮词」。首次启动显示词本主页面，选择词本后点击「悬浮学习」。再次启动会恢复词本、单词位置和外观。
7. 关闭主页面右上角的 ×，或在系统托盘中选择「退出浮词」，会退出软件并关闭桌面卡片。需要返回卡片时，点击「悬浮学习」。

安装位置为 `%LOCALAPPDATA%\Programs\WordFloat`，无需管理员权限。实际程序及运行库位于其中的 `app` 文件夹；安装程序已内置完整词库和应用运行环境，安装无需联网下载。更新时重新运行最新版安装 EXE，会请求已有浮词正常退出，再校验并替换程序。重复打开软件会唤出已有实例。

安装失败会显示「安装未完成」和错误原因，可选择「重试」或「查看安装日志」。安装日志位于 `%LOCALAPPDATA%\WordFloat\SetupLogs`。只有安装进程正常结束并返回对应版本的成功结果，才进入完成页；进度达到 100% 本身不会被视为安装成功。

另提供「浮词-Windows-x64-1.4.1.zip」作为文件夹版：先**完整解压**，再双击 `WordFloatSetup.exe` 或 `Install.cmd` 打开同一安装向导；也可双击 `Start.cmd` 免安装打开。请保留全部文件和 `app` 子目录，不要单独复制 EXE。`SafeMode.cmd` 可使用软件渲染并关闭系统玻璃材质，学习数据和卡片功能相同。

可在 Windows「设置 → 应用」中卸载，或使用开始菜单「浮词 → 卸载浮词」。卸载保留学习进度和外观设置；本地数据位于 `%LOCALAPPDATA%\WordFloat`。

本版不再使用 1.0.0 的压缩单文件入口；完整运行库直接随包提供，避免启动前的解压依赖。系统语音延迟到点击朗读时才初始化，不再阻挡首次显示窗口。

安装向导使用目标系统自带的 .NET Framework 4.8／4.8.1，应用使用随包提供的私有 .NET 10 运行库，无需另装运行环境。系统组件的版本说明见 [Microsoft .NET Framework 安装说明](https://learn.microsoft.com/en-us/dotnet/framework/install/on-windows-10)。

本地构建尚未进行 Windows 代码签名，系统可能显示未知发布者。安装包与文件夹版同时提供来源与许可说明，交付目录提供 SHA-256 校验值。

## 主页面查词

主页面顶部新增「查单词」搜索栏，输入英文单词、短语或中文关键词，即可查询全部内置词库。按 Ctrl+F 聚焦输入，点击「清空」或按 Esc 返回原页面；词本名称筛选仍独立保留。

查询支持大小写与首尾空格，精确匹配优先，其次为前缀；跨词本同词去重，每次最多显示 100 条。选择结果可查看音标、词性、完整中文释义、所属词本及领域释义、已收录的词源／词形／双语例句。点击矢量喇叭「听发音」才朗读，查询和选词不自动发音。查词不会修改当前学习词本或进度。

查询覆盖随应用提供的 12,369 个独立词条，可断网使用；未收录的内容会显示提示，不是联网词典，也不会自动补造缺失资料。发音使用本机系统声音，可在左侧切换英美音。

## 卡片操作

- 卡片默认约 260×150，置于普通应用窗口上方；尺寸会随 Windows 显示缩放调整。
- **单击正文只展开释义，不发音**；再次单击收回最小卡片。
- 点击底部小喇叭才会朗读单词。发音按钮使用清晰的矢量喇叭及声波图标，随字体配色变化，适配显示缩放。
- 在内容区域左拖进入下一词，右拖回到上一词；支持系统派发的触控板横向滚动事件。首尾循环，翻词停止旧发音并隐藏释义。
- 拖动顶部短横线区域移动位置；双击正文打开主页面。
- 鼠标移至卡片边缘或四角，出现缩放光标后拖动调整大小。宽度为 220～520，高度为 130～420；展开释义时最小高度为 200，实际像素随 Windows 显示缩放调整。
- 收起和展开分别记住高度、共用宽度，退出再打开仍保留。再次单击收起或翻词时回到自定义小卡片尺寸。缩放会取消待判定单击，不会触发发音或翻词。
- 展开中文后向下滚动，查看完整词典释义、词根与词源、词形、双语例句、补充义项和英英释义。滚动条采用透明底槽和卡片同色系圆角滑块，悬停、拖动时加深；支持滚轮、拖动滑块和点击轨道翻页。
- 例句支持「英文」「中文」「中英连读」。朗读按钮不会收起卡片；重新朗读或翻词会停止旧队列。

托盘菜单可以显示／隐藏卡片、打开单词本、切换口音和退出。主页面快捷键：Ctrl+1 单词本、Ctrl+2 悬浮学习、Ctrl+Q 退出；词条浏览页面按 Esc 返回词本。

## 词本、外观与离线发音

包含中考、高考、四级、六级、雅思、托福，以及汽车设计、工业设计、材料和剑雅4–19听力答案词，共 10 个词本、28,591 条词本记录、12,369 个独立词条，与现有 Mac 版使用同一词库。支持分类、词本名称／领域搜索和词条中英文搜索；每个词本独立记住浏览位置。

主页面选择「卡片外观」：

- 六种预设：跟随系统、雾面玻璃、清透玻璃、暖白纸卡、鼠尾草、午夜蓝。
- 系统色盘可选卡片颜色、字体颜色，滑块可调整染色浓度。
- 「图片壁纸…」导入 PNG、JPEG、BMP 或 TIFF，最大 50 MB；图片另存到应用本地目录，移动原图不影响使用。
- 预览和保存即时生效；可移除壁纸或恢复默认。

Windows 10/11 统一使用逐像素透明窗口。雾面与清透预设采用半透明染色，在“卡片外观 → 背景不透明度”调整背景；文字与按钮保持清晰。纯色、图片壁纸、高对比度及兼容启动使用实色表面。半透明不是实时模糊桌面，当前版本不承诺 macOS 式背景磨砂。

词库、词源和例句均随程序离线提供，无账号、云同步或付费接口。1,563 个词有来源词源，5,158 个词有双语例句，共 12,086 对；没有收录的内容会明确显示「暂无」，不会猜造词源。例句按通用用法收录，未必对应当前专业词义，原始语料也可能有翻译偏差。

发音使用 Windows 本机系统语音。可切换英音／美音，并使用已安装的中文声音；缺少所选声音时会回退到可用的同语言声音或提示安装。只有系统语音接口可列出的本机声音才能使用。安装声音后重新打开应用；断网时已安装的声音仍可使用。

主页面或托盘「隐私与词库来源」以及每条例句下方保留来源与许可。只有主动点击来源链接时才会打开浏览器。

## 无提示打不开时

1. 安装 EXE 打不开时先记录系统提示；安装过程失败可在失败页查看安装日志。已安装或使用文件夹版时，运行安装目录／完整解压目录中的 `Start.cmd`；不要在压缩包里直接运行，也不要单独挪出 `app/WordFloat.exe`。
2. 运行 `SafeMode.cmd` 尝试兼容启动。这个入口只为本次运行关闭 GPU 渲染和玻璃效果，不修改学习进度或外观设置。
3. 启动失败会显示错误，命令窗口会保留。日志目录是 `%LOCALAPPDATA%\WordFloat`：`startup.log` 记录应用代码进度，`launcher-error.log` 记录安装／启动脚本错误；`Logs` 下每次启动分别保存 `launch.json`、`host.log`、`stderr.log` 等。没有进入应用代码的运行库错误也可由启动器记录。日志不包含其他应用截图。
4. 请提供错误原文及最近一次 `Logs` 子目录的日志，以判断是系统版本、文件损坏、运行环境、窗口创建还是其他问题。**当前收到的现象仅为“无提示”，尚未拿到故障电脑日志，不能确认根因。** 如果是组织策略或系统安全软件阻止执行，请提供其提示；本工具不会更改系统安全策略。

`Diagnose.cmd` 会在软件渲染模式下运行独立的 WPF 窗口与操作检查，使用静音发音替身和隔离学习设置，不改变真实学习进度；输出文件夹会弹窗显示。结果位于 `checks/windows-checks.json`，并包含应用自己的窗口截图，不截取其他应用。诊断入口仍依赖 WPF 能正常启动，不能代替启动器日志，也不证明物理声音或真实磨砂效果。完整范围见同目录「Windows验收记录.md」。

## 从源码构建

安装 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)，在项目根目录执行（PowerShell）：

```powershell
dotnet run --project Windows/WordFloat.Checks -c Release -- "$PWD"
dotnet run --project Windows/WordFloat.Setup.Checks -c Release
dotnet publish Windows/WordFloat.Desktop -c Release -r win-x64 --self-contained true -p:PublishProfile=win-x64-folder -p:DebugType=None -p:DebugSymbols=false -o work/windows-folder
```

发布目录是完整的自包含应用，必须保留全部文件和子目录。`Windows/Launcher` 中的脚本不依赖本应用的 .NET 运行库，打包工具会将脚本和完整发布目录放在一起，并生成逐文件 SHA-256 清单供启动器验证。

如需制作与交付相同的独立安装 EXE 和 ZIP，安装 Python 3.9 及以上，再执行：

```powershell
python Scripts/package_windows.py --publish-dir work/windows-folder
dotnet run --project Windows/WordFloat.Setup.Checks -c Release -- work/windows-setup/payload.zip work/windows-setup/metadata.json
```

打包工具先生成小型文件夹安装向导，再把完整应用和脚本嵌入独立安装 EXE，输出两个下载包及校验报告。首次构建向导需要从 NuGet 还原官方 .NET Framework 4.8 引用程序集，仅构建机器需要联网；用户安装时无需下载。

macOS 构建可直接执行 `sh Scripts/package_windows.sh`，脚本优先使用项目 `work/dotnet` 中的 SDK，避免改动系统工具链。已提交的 SQLite 和学习 JSON 足够重新构建，无需重新下载原始词库。

程序采用自包含文件夹发布，运行库与 Windows 桌面依赖随程序提供；部署机制参见 [Microsoft .NET 部署说明](https://learn.microsoft.com/en-us/dotnet/core/deploying/)。旧版单文件的原生库需要在启动前解压，参见 [Microsoft 单文件部署说明](https://learn.microsoft.com/en-us/dotnet/core/deploying/single-file/overview)。内容来源及覆盖边界见「词库来源.md」。
